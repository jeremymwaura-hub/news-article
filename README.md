# News Article Text Analysis (Moringa School Student Project)

This is a small Python project created as a learning exercise by a Moringa School student who is new to Python.

Features

- Count how many times a specific word appears
- Find the most common word
- Calculate average word length
- Count paragraphs
- Count sentences

How to run

1. Activate the virtual environment (PowerShell):

```powershell
Set-Location 'c:\Users\r3ap3r_2314\Documents\my-work\Moringa_School\news-article'
.venv\Scripts\Activate.ps1
```

2. Run the script:

```powershell
.venv\Scripts\python.exe pythonAssessment.py
```
